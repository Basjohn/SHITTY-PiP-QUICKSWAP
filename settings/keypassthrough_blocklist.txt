# How to use (one entry per line):
# - You can write plain lines (no JSON) OR a JSON object per line.
# - Plain line rules:
#   * Ends with .exe  => match by process name (exe), case-insensitive
#   * Otherwise       => match window title (contains); if multiple words, ALL must be present
# - JSON object rules (advanced):
#   {"exe": "cs2.exe"}
#   {"title_exact": "PUBERTY SIMULATOR"}
#   {"title_contains": "genshin impact"}
# - Comments start with # and are ignored. Blank lines are OK. Trailing commas on a line are ignored.
#

# cs2.exe
# valorant
# genshin impact
